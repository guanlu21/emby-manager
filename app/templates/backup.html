从文件恢复

适合换机器（比如从拾光坞 N3 换到 G2）、重装容器后把数据搬回来。 上传本工具导出的 .zip 备份包即可；也可以直接上传 app.db。

  • 上传后系统会先校验文件：不是本工具的数据库、文件损坏、结构不符都会直接拒绝，当前数据不受影响。
  • 校验通过后会先自动备份当前数据（来源标记为「恢复前自动」），再覆盖。
  • 恢复的内容包括：Emby 地址和 API Key、管理员密码、用户记录（含密码、权限、到期时间）、青龙 Token、日志。
  • 恢复后本工具会立刻按恢复到的用户数据工作，Emby 服务器上已有的账号不会被改动。

自动备份

开启后，容器会按间隔自动生成备份包，并且只保留最近的若干份，不会把数据卷撑满。

备份包里有什么 / 注意什么

  • 备份包内是 app.db（SQLite 数据库）和 meta.json（生成时间、版本、架构、用户数等）。
  • 数据库里包含 Emby API Key、管理员密码哈希、用户密码，备份包请当敏感文件保管，不要随便发到群里或公开网盘。
  • 备份只覆盖本工具自己的数据，不含 Emby 服务器的媒体库、用户观看记录；那些属于 Emby 自身。
  • 换机器恢复的顺序建议：新机器上先用同样的数据卷路径把容器跑起来 → 恢复备份 → 到「设置」里确认 Emby 地址和 API Key 能连通（如果新机器换了 IP，需要改一下）。
