# Emby 用户管理面板（自建，适配 arm64 / 拾光坞 N3）

一个轻量的 Emby 用户管理后台，功能：

- 新建 Emby 用户（用户名 + 初始密码）
- 勾选该用户可访问的媒体库
- 开关"允许下载"、"允许上传（相机上传）"
- 设置使用期限（7/30/90/365 天 或自定义日期，也可永久）
- 到期自动停用账号（每小时检查一次）
- 一键续期 / 手动停用 / 启用 / 删除
- 提供接口给青龙面板轮询，配合青龙内置的 `sendNotify` 在到期前提醒、到期后通知

技术栈：Python + FastAPI + SQLite，单容器运行，无需额外数据库。

---

## 重要说明：关于 arm64 镜像

这份交付是**完整、可运行的源代码 + 一套让你零 SSH 也能拿到 arm64 镜像的构建流程**（用 GitHub 的免费服务器帮你构建arm64镜像，你只负责点一下按钮/填一个地址）。

请根据你 NAS 上"可视化 Docker 面板"支持的方式，三选一：

### 方式一：面板支持"从 Dockerfile / Compose 构建"（最简单，推荐先看这个）

如果你的 拾光坞N3 Docker 面板里，新建容器时有类似"从 Dockerfile 构建""上传源码构建""docker-compose 导入"的选项，那最省事：

1. 把这整个文件夹打包上传到面板（或者先上传到你能访问的任意路径）。
2. 面板里选择"从 Dockerfile 构建"，构建过程本来就是在你的 NAS（arm64）上原生进行的，天然就是 arm64，**完全不会有架构不匹配的问题**。
3. 构建完成后，映射端口 `8000`，挂载一个数据卷到容器内的 `/app/data`（否则重建容器数据会丢失）。

这种情况下你甚至不需要 GitHub。

### 方式二：面板只支持"拉取镜像"（填镜像地址）

用 GitHub 的免费 CI 帮你把 arm64 镜像构建好并发布，你只需要在面板里填一个地址去拉取：

1. 注册/登录 GitHub（免费），新建一个仓库，比如叫 `emby-manager`。
2. 把这个文件夹里的所有文件上传到该仓库（网页端就能拖拽上传，不需要命令行）。
3. 仓库里已经包含 `.github/workflows/build.yml`，上传后 GitHub 会自动开始构建（在仓库的 "Actions" 标签页可以看到进度，几分钟后完成）。
4. 构建完成后，镜像会自动发布到：
   ```
   ghcr.io/你的GitHub用户名/emby-manager:latest
   ```
   （首次发布的镜像包默认是 private，需要去仓库右侧 "Packages" 里把这个包的可见性改成 Public，否则 NAS 拉取会因为没有登录凭证而失败）
5. 在拾光坞 N3 的 Docker 面板里，"添加容器" -> "拉取镜像" -> 镜像地址填第4步那个地址 -> 端口映射 `8000:8000` -> 数据卷挂载 `/app/data` -> 启动。

### 方式三：面板只支持"导入本地镜像文件（.tar）"

跟你最开始遇到的情况一样，面板只能导入 tar 包：

1. 同方式二的第 1-3 步，把代码上传 GitHub 触发 Actions 构建。
2. 构建完成后，进入该次 Actions 运行记录页面，下方 "Artifacts" 里能下载到 `emby-manager-arm64.zip`，解压后就是 `emby-manager-arm64.tar`——这份是已经编译好的 **arm64** 镜像，直接导入拾光坞N3的 Docker 面板即可，无需 SSH、无需本地 docker 环境。

## 首次使用

1. 容器启动后，浏览器访问 `http://NAS的IP:8000`
2. 首次会要求设置"管理员密码"（这是保护本管理面板的密码，不是 Emby 密码）
3. 登录后进入「设置」页：
   - 填写 Emby 服务器地址（如果 Emby 和本容器在同一个 docker 网络，可以直接用容器名，比如 `http://emby:8096`；否则用 NAS 局域网 IP，比如 `http://192.168.1.10:8096`）
   - 填写 Emby API Key（Emby 后台 -> 高级 -> API 密钥 -> 新建）
   - 保存后会自动测试连接
4. 回到「用户列表」，点「新建用户」，勾选媒体库、设置期限、开关下载/上传权限即可

## 配置青龙到期提醒

1. 「设置」页会显示一个专属 Token 和接口地址（`/api/qinglong/report?token=xxx&days=3`）
2. 把仓库里的 `qinglong_notify_example.js` 内容复制到青龙面板"脚本管理"里新建一个脚本，
   按脚本内注释修改两处：接口地址（容器名或IP）、Token
3. 青龙"定时任务"里给这个脚本配置 cron，比如每天 9:00 和 20:00 各跑一次：`0 9,20 * * *`
4. 确认青龙自己的「通知设置」里已经配置好推送方式（Bark/钉钉/企业微信/Server酱/Telegram 等）——
   本脚本调用的是青龙自带的 `sendNotify`，会自动用你已配置好的那个通道推送，不需要额外配置

脚本会推送两类消息：
- **今日到期，已自动停用**：本服务每小时会自动检查一次，到期就会调用 Emby 把账号禁用
- **即将到期（N天内）**：默认提前3天提醒，可以在脚本里改 `DAYS_BEFORE`

## 关于"允许上传"的说明

Emby 本身不是网盘类应用，没有普适的"用户上传媒体文件"功能。这里的"允许上传"对应 Emby 的
`AllowCameraUpload`（移动端 App 的相机自动上传）策略位，是 Emby 原生支持的、最接近"上传"语义的开关。
如果你说的"上传"另有所指（比如某个特定第三方 Emby 客户端的功能），可以告诉我具体是哪个客户端/哪个开关，我再补充对应字段。

## 批量操作

- **批量创建用户**：用户列表页点「批量创建用户」，一行填一个用户名，可以选择「统一密码」或「每人随机生成密码」
  （随机密码只在创建结果页显示一次，记得当场复制保存），到期时间/媒体库/下载上传权限对本批次所有用户统一生效。
- **批量续期 / 停用 / 启用 / 删除**：用户列表左上角勾选要操作的用户（表头有"全选"），点对应按钮即可批量处理。
